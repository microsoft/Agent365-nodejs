# Support

## How to file issues and get help

This project uses [GitHub Issues](https://github.com/microsoft/Agent365-nodejs/issues) to track bugs and feature requests. Please search the existing issues before filing new issues to avoid duplicates. For new issues, file your bug or feature request as a new issue.

For help and questions about using this SDK, please refer to the [Microsoft Agent 365 developer documentation](https://learn.microsoft.com/microsoft-agent-365/developer/).

## Security issues

Do not report security vulnerabilities through GitHub Issues. Follow the instructions in [SECURITY.md](SECURITY.md).

## Microsoft Support Policy

Support for this project is limited to the resources listed above. This is an open-source project; Microsoft product support contracts and service-level agreements (SLAs) do not extend to this repository.
